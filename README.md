# picbed

## 介绍
图床，存放 Markdown / 博客中引用的图片。

- 上传工具：PicGo
- 分支：`main`
- 外链格式：
  - Gitee：`https://gitee.com/zerocn/picbed/raw/main/<文件路径>`
  - GitHub：`https://raw.githubusercontent.com/cnzeropro/picbed/main/<文件路径>`
- 现有目录：`favicon/`

> 仓库名会嵌入所有图片外链。由 `pic` 改为 `picbed` 后，实测新旧 raw 外链在 Gitee / GitHub **均仍可用**（两端都会保留旧路径别名），但该别名可能因旧路径被重新注册而失效，故不建议再次改名。
